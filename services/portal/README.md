# portal — личный кабинет клиента

Поток C, файл [`docs/04-stream-c-billing-accounts.md`](../../docs/04-stream-c-billing-accounts.md).

## Одно число, потому что источник один

> «Остаток из `wms` по ячейкам и коробкам — не зеркало кабинета WB, как сейчас
> (портал показывает 3528 единиц при реальном остатке 92 — это должно стать
> одним числом, потому что источник один).»

**В базе портала нет и не будет таблицы остатков.** Портал спрашивает склад при
каждом показе. Зеркало, заведённое «для скорости», вернёт расхождение в тот же
день — и вернёт его клиенту, а не нам. На это есть тест: он падает, если в
схеме появится ещё одна таблица.

По той же причине упавший склад даёт **502, а не вчерашнее число**: показать
устаревший остаток вместо отказа — это те же 3528 против 92, только другим
путём.

## Что видит клиент

| Экран | Что показывает |
|---|---|
| **Остаток** | свободно / в резерве / на полке, по товарам и по коробкам с ячейками — тот же остаток, что видит сборщик |
| **Начисления** | расшифровка с **видимой наценкой партнёра**: 45 ₽ = 30 MM-Express + 15 партнёру |
| **Выгрузки** | акт за период клиент забирает сам, без участия бухгалтера |

Разбивка цены — не украшение. Итог без неё читается как «MM-Express берёт 45»,
и клиент считает нас источником завышенной цены вместо того, чтобы понимать,
что 15 — наценка того, кто его привёл (раздел 1 мастера).

Коробка и её комментарий показываются клиенту так же, как сборщику: коробка —
фактическая единица адресации склада (раздел 2.9), и комментарий у неё
обязателен, потому что через месяц на складе стоят сотни одинаковых.

## Чей кабинет

Из области роли (`seller` в [`identity`](../identity/README.md)), а не из
параметра запроса: иначе достаточно подставить чужой ключ продавца, чтобы
увидеть чужой остаток. Пользователю без области портал отказывает и **говорит
почему** — пустой экран читается как «у вас ничего нет» и прячет причину.

Акт скачивается через `fetch` с заголовком, а не ссылкой: токен в адресной
строке — это токен в истории браузера и в логе прокси.

## Запуск и тесты

Поднимается наложением потока C, порт `127.0.0.1:8086`.

```bash
cd services/portal
APP_ENV=test PORTAL_TEST_DATABASE_URL=postgresql://wms:…@127.0.0.1:5432/postgres \
  python -m pytest -q
```
