# internal-admin — админка MM-Express

Поток C, файл [`docs/04-stream-c-billing-accounts.md`](../../docs/04-stream-c-billing-accounts.md).

## Зачем

«Онбординг клиента одним потоком… Ни одного ручного SQL-запроса в процессе.
Сейчас 21 кабинет WB заведены при 4 записях в `sellers` — это ручной,
непоследовательный процесс, который должен исчезнуть.»

## Чего здесь нет

Ни одного правила о деньгах. Админка не считает наценку, не выбирает версию
тарифа и не решает, что тарифицируется, — всё это в [`billing`](../billing/README.md).
Вторая копия правил однажды разойдётся с первой, и разойдётся она в счёте
клиента.

Прав админка тоже не считает: токен пользователя прокидывается в биллинг
насквозь, а тот спрашивает `identity`. Проверка в двух местах однажды
разойдётся — в пользу показать лишнее.

## Что здесь есть

| Экран | Что решает |
|---|---|
| **Обзор** | три числа, которых сегодня нет ни у кого: кабинетов заведено мимо процесса, операций склада без начисления, убыточных кабинетов. Именно их отсутствие позволяет 6374 заданиям превращаться в 145 начислений незамеченно |
| **Онбординг** | договор → тариф → партнёр → кабинет WB → владелец в складе → начальный остаток, одним нажатием |
| **Партнёры** | дерево менеджеров, наценка по услуге с даты, комиссия по ветке |
| **Тарифы** | семь услуг, версии, утверждение (цена без подписи в счёт не идёт) |
| **Начисления** | расшифровка: клиент платит 45, из них 30 нам и 15 партнёру |
| **Журнал** | кто, когда и что сделал — **вторая половина** правила «ни одного ручного SQL» |

Журнал пишет и неудачи: попытка, окончившаяся отказом, нужна при разборе не
меньше удачной — по ней и выясняют, почему клиент не завёлся.

Начальный остаток в журнал целиком не кладётся (раздувает строку), `secret_ref`
кладётся — это ссылка, а не секрет, и видеть её как раз нужно.

## Онбординг и вызовы в склад

Заведение в биллинге идёт транзакцией, а вызовы в `wms` — снаружи неё
(инвариант 2 мастера). Откатить чужой сервис нечем, поэтому честный ответ на
упавший шаг — «сделано столько-то, повторить с такого», а не молчаливый успех
и не потерянный наполовину клиент. Экран показывает шаги по одному.

Повтор безвреден: договор идемпотентен по номеру, кабинет — по ключу продавца,
закрепление за тем же партнёром в тот же день ничего не меняет.

## Фронт

Ванильный JS (раздел 2.2 мастера): ни сборки, ни фреймворка. Экран админки
меняется реже, чем правила денег, и держать ради него отдельный тулчейн дороже,
чем написать двести строк.

## Запуск и тесты

Поднимается наложением потока C, порт `127.0.0.1:8085`. Вход — токен
`stand:<uuid пользователя>` (см. [identity](../identity/README.md)).

```bash
cd services/internal-admin
APP_ENV=test ADMIN_TEST_DATABASE_URL=postgresql://wms:…@127.0.0.1:5432/postgres \
  python -m pytest -q
```
